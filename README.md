# 眉县预报快照仓库

本仓库由 GitHub Actions 自动维护，每天6次抓取中央气象台的眉县逐日预报、逐3小时预报与站点逐小时实况，同时尝试抓取中国天气网的7天与8至15天预报页面，原样保存为压缩快照。快照由桌面程序“眉县降水预报检验”同步到本机以后解析入库，用于官方预报与 WeatherNext 3 的准确性对比。

## 目录

| 路径 | 内容 |
|---|---|
| `snapshots/年/月/日/` | 每次抓取的原始网页与接口响应，gzip 压缩，文件名为 数据源_时分秒，时间为北京时间 |
| `index/年-月.json` | 当月全部快照的清单 |
| `latest.json` | 最近一次运行的时间、结果与最新快照时间 |
| `collect_snapshots.py` | 抓取脚本，只使用 Python 标准库 |
| `.github/workflows/collect.yml` | 定时运行的配置，运行时刻为北京时间8时30分、12时30分、15时30分、17时30分、20时30分、22时30分 |

## 说明

- 仓库内容不需要手工修改。桌面程序只读取本仓库，不向本仓库写入。
- 抓取结果可以在仓库页面的 Actions 标签下查看。中央气象台的两项数据源同时失败的时候，运行记录标记为失败，GitHub 会向仓库所有者发送邮件。
- 数据来源为中央气象台与中国天气网的公开网页，仅用于个人研究对比。
